# KIWI Compiler: General Purpose Programming Language 
### Work in Progress:
  Currently working on Frontend Development.
This project is a toy compiler written in C++. I'm building a compiler from scratch to understand how it works under the hood.

## Example Code
An example `add` function written in KIWI:
```KIWI
fn add(int32 a, int32 b) -> int32 {
  return a + b;
}
```
